# 🍕 Park’s Pizza Sales Analysis (Power BI)

## 📌 Project Overview
This project analyzes pizza sales data to uncover key business insights around revenue performance, customer behavior, and product optimization using Power BI.

---

## 🎯 Objectives
- Identify top-performing products and categories  
- Analyze sales trends across time (daily & monthly)  
- Understand customer ordering behavior  
- Provide actionable recommendations for business growth  

---

## 🛠️ Tools & Technologies
- Power BI (Dashboard & Data Modeling)
- DAX (Calculated Measures)
- Microsoft Excel (Data Cleaning)
- Dataset: Kaggle Pizza Sales Dataset  

---

## 📊 Key Metrics
- Total Revenue: **$817.9K**
- Total Orders: **21K**
- Total Pizzas Sold: **50K**
- Average Order Value: **$38.31**
- Avg Pizzas per Order: **2.32**

---

## 📈 Key Insights

### 🔹 Time-Based Trends
- Friday generates the highest revenue  
- Sunday consistently underperforms  
- Sales peak during weekends  

### 🔹 Product Performance
- Top Products: Thai Chicken, Barbecue Chicken  
- Lowest Products: Brie Carre, Green Garden  

### 🔹 Size Preference
- Large pizzas dominate sales  
- Extra-large sizes contribute minimal revenue
